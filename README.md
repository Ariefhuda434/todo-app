# 📝 React Todo List Application

Aplikasi **Todo List** sederhana dan responsif yang dibangun menggunakan **React.js**. Aplikasi ini memungkinkan pengguna untuk menambahkan, menandai sebagai selesai, dan menghapus tugas harian dengan antarmuka yang bersih dan mudah digunakan.

## Fitur Utama

- ✅ **Tambah Tugas**: Menambahkan tugas baru dengan cepat.
- ✅ **Tandai Selesai**: Memberi tanda pada tugas yang sudah selesai dilakukan.
- ✅ **Hapus Tugas**: Menghapus tugas yang sudah tidak diperlukan.
- ✅ **Penyimpanan Lokal**: Data tugas tersimpan di `localStorage` browser, sehingga tidak hilang saat halaman dimuat ulang.
- ✅ **Responsif**: Tampilan menyesuaikan dengan berbagai ukuran layar (Desktop & Mobile).

## Teknologi yang Digunakan

- **[React](https://reactjs.org/)**: Library JavaScript untuk membangun antarmuka pengguna.
- **Create React App**: Boilerplate untuk setup proyek yang cepat.
- **CSS3**: Styling kustom untuk tampilan yang modern.
- **LocalStorage API**: Untuk persistensi data sederhana di sisi klien.
